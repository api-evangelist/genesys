# Genesys Cloud Platform API

> Genesys is a global cloud customer experience (CX) and contact center software company. The Genesys Cloud Platform API is an OAuth 2 secured REST API of more than 3,000 public operations covering conversations, routing, analytics, telephony edge, workforce management, knowledge, journey, outbound, quality, integrations, and administration. It is described by a public OpenAPI (Swagger 2.0) definition and supported by official SDKs, a CLI, and a websocket notifications event surface.

## APIs
- [Genesys Cloud Platform API](https://developer.genesys.cloud/platform/api/): 3,000+ operation REST API for the Genesys Cloud CX platform (base host https://api.mypurecloud.com)

## Specs
- [OpenAPI (Swagger 2.0)](https://api.mypurecloud.com/api/v2/docs/swagger): the full Platform API definition (2,139 paths / 3,180 operations)

## Authentication
- [Platform auth overview](https://developer.genesys.cloud/authorization/platform-auth/): OAuth 2 (authorization_code + PKCE, client_credentials, refresh_token, SAML2 bearer, implicit)
- [OAuth scopes reference](https://developer.genesys.cloud/authorization/scopes/): 135+ scopes, opt-in enforcement
- [Authorization server metadata](https://login.mypurecloud.com/.well-known/oauth-authorization-server): RFC 8414
