Genesys is a global cloud customer experience (CX) and contact center software company whose flagship Genesys Cloud CX platform powers omnichannel customer engagement, routing, workforce management, and AI-driven orchestration. The Genesys Cloud Platform API is a large REST API of more than 3,000 public operations spanning conversations, routing, analytics, telephony (edge), workforce management, knowledge, journey, outbound, quality, gamification, integrations, and administration. It is secured with OAuth 2, described by a public OpenAPI (Swagger 2.0) definition, and supported by official SDKs for Java, .NET, Python, Go, JavaScript/Node, and iOS/Swift, a command-line interface, a notifications/websocket event surface, and a weekly changelog.

**Areas:** Company · Software · Contact Center · Customer Experience · CCaaS · Telephony · Conversational AI · Workforce Management · Cloud Communications · CPaaS · Customer Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Genesys: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
